# Robotics Systems Design

This repository contains the class repository structure for Robotics Systems Design.

Students can either:

1. Clone this repository directly, or
2. Fork this repository to their own GitHub account and work from the fork.

## If You Clone The Repository

Clone the class repository:

```bash
git clone https://github.com/NM-TAFE/robotics-systems-design.git
cd robotics-systems-design
```

## If You Fork The Repository

If you fork this repository, you should add the class repository as an `upstream` remote so you can pull future changes from the teaching repository.

Clone your fork:

```bash
git clone https://github.com/<your-github-username>/robotics-systems-design.git
cd robotics-systems-design
```

Add the class repository as `upstream`:

```bash
git remote add upstream https://github.com/NM-TAFE/robotics-systems-design.git
git remote -v
```

Fetch updates from the class repository:

```bash
git fetch upstream
```

Merge changes from the class repository into your local branch when needed:

```bash
git merge upstream/main
```

## Session Structure

The repository includes directories for:

- `Session 1` to `Session 17`
- `code-example` inside each session
- `activities` inside each session
